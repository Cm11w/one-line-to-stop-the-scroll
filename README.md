One line of text, at most 200 characters, written to make a stranger stop
scrolling and smile — entered in the
[One Line to Stop the Scroll](https://make.fun/bounty/u-febri-yudila-one-line-to-stop-the-scroll-e8b18425)
bounty on make.fun.

## The line

> At 6:20 this morning, Mrs. Hartono held a handwritten sign to her window: ‘Your laugh fixed my radio.’ I have never once heard her radio, but I laughed louder, just in case.

## How it works

`main.ts` is a dependency-free Node program. It holds the line, validates it
against the competition gate (1–200 characters, not only white space, a
single line), and writes it to `/output/entry.txt` — the path the kit's
harness reads. No network, no assets, nothing else: the line is the whole
entry.

Run it:

```sh
node main.ts
```
